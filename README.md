# 🎯 Анализатор вакансий с hh.ru

Профессиональный инструмент для поиска, анализа и управления вакансиями с платформы HeadHunter. 
Проект реализован с использованием современных практик Python-разработки и принципов ООП.

## ✨ Возможности

### 🔍 Поиск и сбор данных
- **Интеграция с API HH.ru** - автоматический сбор вакансий по ключевым словам
- **Параметризованные запросы** - настройка количества результатов, региона поиска
- **Обработка ошибок** - устойчивость к сетевым проблемам и ошибкам API

### 💾 Умное хранение
- **Многформатное хранение** - поддержка JSON и TXT форматов
- **Предотвращение дубликатов** - автоматическое обнаружение и исключение повторяющихся вакансий
- **Гибкие запросы** - фильтрация по различным критериям

### 📊 Анализ и фильтрация
- **Фильтрация по зарплате** - диапазонные запросы и сравнение вакансий
- **Поиск по ключевым словам** - интеллектуальный поиск в описаниях и требованиях
- **Сортировка** - упорядочивание по убыванию зарплаты
- **Топ-N выборка** - получение лучших вакансий

### 🎨 Пользовательский интерфейс
- **Интерактивный CLI** - понятный диалог с пользователем
- **Читаемый вывод** - красивое форматирование результатов
- **Статистика** - детальная информация о процессе обработки

## 📦 Установка и запуск

### Требования
- Python 3.8+
- pip (менеджер пакетов Python)

### Установка

1. **Клонирование и настройка**
```
git clone <your-repo-url>
cd vacancy_analyzer
```
2. **Создание виртуального окружения**

### Linux/MacOS
```
python -m venv venv
source venv/bin/activate
```
### Windows
```
python -m venv venv
venv\Scripts\activate
```
3. **Установка зависимостей**
```
pip install -r requirements.txt
```
4.Запуск

Основной режим:
```
python src/main.py
```

## Запуск с тестовыми данными
```
python src/main.py --test
```

## Запуск с указанием файла для сохранения
```
python src/main.py --output my_vacancies.json
```
## 🎮 Использование
### Основной сценарий:
1. Запустите программу
2. Введите поисковый запрос - например "Python developer"
3. Укажите количество вакансий - топ 10, 20, 50...
4. Задайте ключевые слова для фильтрации (опционально)
5. Укажите диапазон зарплат (опционально)
6. Получите результат - отфильтрованные и отсортированные вакансии

## 🔧 Настройка
Конфигурация API
Для работы с HH.ru API используются следующие параметры:

python
BASE_URL = "https://api.hh.ru/vacancies"
PARAMS = {
    "text": search_query,
    "per_page": 100,           # Максимум 100 на странице
    "area": 113,               # Россия
    "only_with_salary": True   # Только с указанной зарплатой
}
Форматы хранения
JSON (рекомендуемый):

json
[
  {
    "name": "Python Developer",
    "url": "https://hh.ru/vacancy/123",
    "salary": {"from": 100000, "to": 150000, "currency": "RUR"},
    "description": "Разработка web-приложений...",
    "requirements": "Опыт работы 3+ года..."
  }
]
TXT (для простого просмотра):

Вакансия: Python Developer
Ссылка: https://hh.ru/vacancy/123
Зарплата: 100000-150000 RUR
